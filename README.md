# 🎂 Age & Birthday Counter

A simple, responsive web application built with **HTML5**, **CSS3**, and **JavaScript** that calculates the number of days that have passed since your birth date, or the number of days remaining until your next birthday!

## ✨ Features

- **Date Calculation:** Automatically compares your selected date with the current date.
- **Past & Future Handling:** 
  - If the date is in the past, it shows how many days have passed since your birth.
  - If the date is in the future/today, it shows how many days are left until your birthday.
- **Interactive Pop-up Modal:** Displays the results neatly inside a styled alert box with a custom cake icon.
- **Fully Responsive:** Adapts seamlessly to various screen sizes (desktops, tablets, and mobile devices) using CSS Media Queries.

---

## 🛠️ Built With

- **HTML5** – Structure of the application
- **CSS3** – Styling, flexbox layout, shadows, and transitions
- **JavaScript (ES6)** – Date logic and DOM manipulation
